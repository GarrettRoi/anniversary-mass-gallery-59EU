# Archdiocese of Oklahoma City - Anniversary Mass Photo Booth Gallery

**Project ID:** 59EU-anniversary-mass-2026 | **Event:** November 8, 2026 | **Client contact:** Carrie Harkey (Archdiocese)

Public gallery of 91 photos. Original booth photos carried a white event banner that covered
the lower portion of the frame; originals without the overlay do not exist anywhere, so each
photo was AI-reconstructed (Nano Banana / Gemini image edit via fal.ai): banner removed,
people's clothing continued to a natural waist-up crop, faces untouched, then gently enhanced.
